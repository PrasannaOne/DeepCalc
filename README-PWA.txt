DeepCalc V6 deployment

Upload the contents of this folder to the repository root (same folder as index.html). Keep the icons folder, manifest.webmanifest, service-worker.js and og-image.png at these exact paths.

GitHub Pages URL configured in metadata: https://prasannaone.github.io/DeepCalc/

PWA install/offline/update features require HTTPS (GitHub Pages provides HTTPS). The service worker caches the app shell for offline launch, checks for updated files on launch/return and periodically, and activates new deployments automatically. Browsers control the exact timing of installed app icon refreshes; clearing the browser's site cache may be needed for an icon to refresh immediately.

Open Graph artwork is 1536x1024 from the approved DeepCalc brand banner.
