Guide

Basics

Type mathematical expressions and see results instantly. Use +, −, ×, ÷ for basic operations, ^ for power, and % for percentage.

Variables

Define variables with $name = value Example: $tax = 0.08 Use them in expressions: 100 × $tax

Line References

Reference previous results with $1, $2, etc. Example: If line 1 equals 50, then $1 × 2 = 100

Keyboard

^ — Power (hold for √ square root) $ — Variables (hold for picker) # — Start a comment ⌫ — Backspace (hold to clear line) ⏎ — New line

Notes

Use the small arrow beside a calculation to open its note. Notes are separate from calculations and do not affect results or line references. Notes use your device keyboard.

Copy and Save

Copy Sheet copies calculations. Copy Complete includes calculations and their notes. Save Sheet stores a separate snapshot in History.

History

Open History to reopen saved sheets, rename them, or delete them. Your active sheet is autosaved separately.
